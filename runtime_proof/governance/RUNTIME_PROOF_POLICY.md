# Runtime Proof Policy

Déclarer avant exécution : objectif, cible, niveau de preuve, population, échantillon, bornes, effets interdits, preuves attendues et STOP.

Statuts distincts : `SUPPORT_IMPLEMENTED`, `SUPPORT_TESTED`, `SUPPORT_RUNTIME_OBSERVED`, `SUPPORT_RUNTIME_NOT_OBSERVED`, `RUNTIME_PROVEN`, `PRODUCTION_VERIFIED`.

Un cas supporté non rencontré dans une petite fenêtre live est `SUPPORT_RUNTIME_NOT_OBSERVED`, pas un échec.
