# Work Items

Ajouter un fichier JSON par Work Item conforme à `../schemas/work-item.v1.schema.json`. L’identifiant interne `WI-NNN` est stable ; `display_reference` dépend seulement du `project_key` facultatif. Une correction significative crée une révision explicite plutôt qu’une réécriture silencieuse d’une preuve close.
