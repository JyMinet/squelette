# Optional Templates

Tout contenu de ce répertoire est :

- `OPTIONAL` ;
- `NOT_ACTIVE` ;
- `NOT_AUTHORITY` ;
- `NOT_PART_OF_CORE`.

Copier et adapter un template exige un besoin établi, une architecture validée, un owner, une version et les décisions applicables. Une nouvelle copie du squelette n’active rien ici automatiquement.
