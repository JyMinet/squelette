# hello-squelette — transcript of one governed change

Generated by `python3 -B examples/hello-squelette/demo.py --write` from a real run of the
controller in a temporary copy of this template. Volatile values are replaced by placeholders
(`<commit>`, `<sha256>`, `<date>`, `<timestamp>`, `<demo>`) and each run of `PASS:` control lines
is folded into a count (`--verbose` keeps them); everything else is the controller's actual output.
`tests/test_template.py` replays the demo and fails if this file or the README block drifts from
what the controller really prints.

## 1. A fresh copy of the template becomes a project

The tracked tree of the template is copied without `.git`: a new project starts its own history. Git is initialized, the pristine copy is committed as the autonomous baseline, then the commit gate is installed outside the worktree — where no commit can carry it away — and every commit is audited from now on.

## 5. The agent proves it has read the authorities, then starts

`context-manifest` lists the documents that govern this Work Item, with their SHA-256 and a global digest. `start` refuses without that digest, and never prints it in its own output: the agent has to go and get it from the authorities as they stand right now. What this proves is narrow and exact — the work started from the current text of every authority, and changing any one of them invalidates the proof until it is acknowledged again. No mechanism can prove that a mind was changed by reading.
